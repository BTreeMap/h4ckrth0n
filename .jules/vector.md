## 2025-02-18 - Functional pure helper patterns for scope manipulation
**Learning:** The CLI tools for user scopes previously relied on multi-step ad hoc state mutations (e.g. manually parsing strings, doing list appends or set logic for removal, and then reserializing). This logic was duplicated across adding and removing scopes and exposed implementation details of the `Scope` type directly in the CLI commands. This repository strongly prefers pulling these shared semantics down into pure functional helpers near the data definition (e.g., in `h4ckath0n.auth.authz`).
**Action:** Always prefer calling centralized pure functional transformations like `add_scopes` and `remove_scopes` rather than writing inline staging logic to update domain concepts like user scopes in CLI or service layers.
